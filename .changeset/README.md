# Changesets

This folder is managed by [changesets](https://github.com/changesets/changesets).
Each markdown file in here describes a pending release: the bump level
(patch/minor/major) and a line for the changelog.

Add one to your PR with:

```bash
bunx changeset
```

See the [Release process](../README.md#release-process) section of the main
README for how these turn into tags and releases.
